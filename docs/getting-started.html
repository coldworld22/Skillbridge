Quick start from the customer ZIP

The summary mirrors docs/getting-started.md so CodeCanyon buyers have an HTML landing page that works online and inside the downloaded bundle.

  1. Upload the archive.
    • Local workstation: move the downloaded ZIP into the project directory.
    • Remote server: transfer the archive with scp or rsync. 
    scp Skillbridge-v1.0.0.zip deploy@example.com:/var/www

    Keep a pristine copy of the ZIP so you can redeploy clean files later.

  2. Extract and position the project.

    Unzip the package, rename the extracted folder to Skillbridge, and switch into the directory so helper scripts find the expected paths. 

    unzip Skillbridge-v1.0.0.zip
mv Skillbridge-v1.0.0 Skillbridge
cd Skillbridge

    Ensure install.sh, docker-compose.yml, and the backend/, frontend/, and nginx/ folders live directly under Skillbridge/.

    On Linux hosts update ownership and permissions so deploy users can run the scripts: 

    sudo chown -R deploy:deploy Skillbridge
chmod +x install.sh scripts/*.sh
  3. Copy environment templates.

    Duplicate each .env.example so both applications and automation read real configuration values before you run the installer. 

    cp .env.example .env
cp backend/.env.example backend/.env
cp backend/.env.production.example backend/.env.production
cp frontend/.env.local.example frontend/.env.local

    Update the new files with URLs, SMTP credentials, and secrets for your environment.

  4. Run the installer.

    Execute the bundled installer to validate prerequisites, copy templates, run database migrations and seeds, and create the initial admin account. 

    ./install.sh

    For unattended production deployments supply the mode, domain, and admin credentials via CLI arguments and environment variables.

  5. Start the services.

    Launch the Docker stack after the installer finishes. Run migrations manually first if you manage containers yourself.

    • Local development: 
      docker compose up --build
    • Production host: 
      docker compose up -d --build

    Manual migration commands:

    docker compose run --rm backend npm run migrate
docker compose run --rm backend npm run seed

    Sign in with the admin credentials you configured and begin customizing SkillBridge.
