# ChatGPT Pricing Overview

This document summarizes the plans currently listed on the [ChatGPT pricing page](https://openai.com/chatgpt/pricing).

## Individual Plans

| Plan | Monthly Price | Key Features |
| --- | --- | --- |
| Free | $0 | Access to GPT-5, real-time web search, limited file uploads/data analysis/image generation/voice mode, macOS desktop app code edits, custom GPT usage, project creation. |
| Plus | $20 | Everything in Free, extended limits for GPT-5 access, messaging, file uploads, data analysis, and image generation; standard/advanced voice with video and screen sharing; ChatGPT agent access; task and custom GPT creation; limited Sora 1 video generation; Codex agent research preview; early feature testing. |
| Pro | $200 | Everything in Plus, unlimited GPT-5 access, GPT-5 Pro for complex answers, unlimited advanced voice with higher video/screen sharing limits, extended ChatGPT agent access, extended Sora 1 video generation, subject to abuse guardrails. |

## Business Plan

- $25 per user/month billed annually ($30 per user/month billed monthly).
- Unlimited GPT-5 messages with generous GPT-5 thinking access and GPT-5 Pro availability.
- Secure, dedicated workspace with admin controls, SAML SSO, MFA, and default data exclusion from training with encryption at rest/in transit.
- Compliance support (GDPR, CCPA, CSA STAR, SOC 2 Type 2, ISO/IEC 27001/27017/27018/27701).
- Connectors for Google Drive, SharePoint, GitHub, Notion, and more.
- Business-specific tools (data analysis, record mode, canvas, shared projects, tasks, workspace GPTs).
- Includes Codex and ChatGPT agent for reasoning/action across documents, tools, and codebases.

## Enterprise Plan

- Pricing via sales (volume discounts, invoicing, ACH billing, unlimited users).
- Everything in Business plus expanded context window for longer inputs/larger files.
- Enterprise-grade security (SCIM, user analytics, domain verification, role-based access controls).
- Advanced data privacy (custom retention policies, encryption, no training on business data by default).
- Support for data residency in seven regions.
- 24/7 priority support, SLAs, custom legal terms, and access to AI advisors for eligible customers.
